# 플랜티프렌즈 5-페르소나 리뷰 체크리스트

## Revenue PM
- [ ] AdSense Auto Ads 기준으로 광고 정책 친화 레이아웃을 유지한다.
- [ ] 푸터 이메일 캡처는 비강제이며 본문 이용을 방해하지 않는다.
- [ ] V1에서는 결제·구독·어필리에이트를 넣지 않는다.

## UX
- [ ] 진단 도구는 지역·환경 quick flow를 먼저 제공한다.
- [ ] 안전성 디스클레이머는 footer 상시 문구와 1회 모달 정책을 따른다.
- [ ] 모바일에서 360px 폭 기준으로 텍스트가 넘치지 않는다.

## Frontend
- [ ] 5만 페이지 초기 prerender를 피하고 ISR 중심으로 설계한다.
- [ ] sitemap index는 식물·가이드·카테고리·꽃말 단위로 분할한다.
- [ ] 내부 API는 `INTERNAL_API_TOKEN` 또는 `CRON_SECRET`으로 보호한다.

## QA
- [ ] 필수 필드가 없으면 자동 비공개 처리한다.
- [ ] 금지어·의료 단정·반려동물 안전 단정을 lint에서 차단한다.
- [ ] dedup은 분류군별 pool을 우선 적용한다.

## Growth
- [ ] 한국 기후 적합도 점수를 Quick Facts와 진단 도구에 노출한다.
- [ ] FAQ와 정량 데이터를 LLM 인용 가능한 짧은 청크로 제공한다.
- [ ] sitemap `lastmod`는 실제 변경 일시를 반영한다.
