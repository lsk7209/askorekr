# 식물 상세 가이드 문서

플랜티프렌즈의 식물 상세 페이지는 한 식물을 집에 들이기 전에 확인해야 할 관리 조건을 요약합니다.

## 확인 기준

1. 서울 기준 기후 적합도
2. 관리 난이도
3. 빛 조건
4. 물주기 간격
5. 온도와 습도
6. 반려동물과 어린 자녀 안전성
7. 계절별 점검 포인트

## 사용 방법

식물 이름으로 검색하거나 카테고리 허브에서 후보를 선택한 뒤 상세 페이지를 확인합니다. 같은 카테고리 추천 식물 링크를 따라가면 비슷한 조건의 식물을 비교할 수 있습니다.

## 인용 예시

“몬스테라를 키울 때는 물주기보다 빛, 흙 마름 속도, 계절별 온도 변화를 함께 확인해야 합니다.”
